# Equalizer APO

A free, open-source system-wide audio processor for Windows. Equalizer APO acts as an Audio Processing Object (APO) driver module that applies parametric and graphic equalization, convolution, VST plugins, and audio effects to all applications at the Windows audio engine level — no per-application setup required.

**Version:** 1.4. **Platforms:** Windows x86 (32-bit), x64, and ARM64.
